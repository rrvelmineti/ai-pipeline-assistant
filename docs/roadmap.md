# Version 1 scope

Implemented: orders CSV checks, exact decimal totals, structured evidence, CLI,
SQLite run history, JSON downloads, local browser demo, constrained optional Gemini
classification, offline unit/integration tests, and Linux/Windows CI.

Not implemented: autonomous diagnosis of arbitrary systems, automatic repairs,
production hosting, authentication, multiple currencies, tax/refund rules or
multi-tenant storage. Live Gemini verification needs a user-provided key and model.

Possible next lessons: order identifiers and duplicate checks, database loading
with transactions, richer evidence-based AI evaluation, and reviewed repair proposals.
Choose one after understanding the current version. Never turn guessed replacements
into source data.
